# TW0 W0RDS prototype

Open `index.html` in any modern browser to play. No installation, server, account, or backend is needed.

The prototype starts on **ICE CREAM** under the **SUMMER** theme. Use **NEXT** to rotate through the Summer and School test set. Blank tiles display `#` for an encoded number and `–` for an encoded letter. Type the full encoded phrase—for example, `1C3 CR34M`: a correctly guessed word turns green, while a selected reveal turns purple. Hints bank after guesses 1, 3, 5, and 7.

## Easy changes

- In `app.js`, change `PUZZLE.answer`, `theme`, and `number`.
- The number substitutions are at the top of `app.js`.
- The visual system lives entirely in `styles.css`.

Use the circular reset button in the upper-right corner to replay the sample from a clean state.
